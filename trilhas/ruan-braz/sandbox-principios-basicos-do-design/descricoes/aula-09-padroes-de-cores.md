# Padrões de Cores

**Tempo estimado de leitura:** 4 minutos

## Objetivos de aprendizado

Ao final desta aula, você será capaz de:

- Distinguir os dois sistemas de cor (CMYK e RGB) e identificar quando aplicar cada um
- Aplicar o sistema de cor correto ao criar arquivos para impressão ou para meios digitais
- Reconhecer os erros mais comuns na escolha do sistema de cor e suas consequências visuais
- Aplicar princípios básicos de harmonização de cores em projetos, usando referências e ferramentas de apoio

## Por que escolher a cor certa não é só uma questão estética

Escolher uma cor para um projeto vai além da preferência visual. Existe uma dimensão técnica nessa escolha que impacta diretamente o resultado final, especialmente quando o suporte muda. O mesmo arquivo pode parecer completamente diferente dependendo de onde ele será exibido ou impresso.

A razão é que cores funcionam de formas distintas conforme o suporte. Cores de luz e cores de pigmento são geradas por mecanismos opostos, e cada um exige um sistema de cor específico. Trabalhar com o sistema errado é um dos erros mais comuns entre designers iniciantes.

## CMYK: o sistema de cor para impressão

CMYK é o sistema de cor usado para meios impressos. A sigla representa as quatro tintas que compõem essa síntese cromática: ciano, magenta, amarelo (yellow) e preto (black). O preto é representado pela letra K, e não B, para evitar confusão com o azul (blue) do sistema RGB.

Esse sistema funciona com pigmentos. Qualquer material que precisa ser impresso fisicamente, como papelaria, outdoors ou embalagens, deve ser criado nesse espaço de cor. Trabalhar em CMYK garante que as cores escolhidas na tela correspondam ao que a gráfica consegue reproduzir com tinta.

Ruan mencionou também a existência do sistema Pantone como outra referência de cor para impressão. Trata-se de um sistema proprietário de cores padronizadas, amplamente usado na indústria gráfica para garantir precisão de cor entre diferentes fornecedores e processos de impressão. O tema não foi aprofundado nesta aula, mas foi indicado como conteúdo disponível em texto complementar abaixo do vídeo.

## RGB: o sistema de cor para telas e luz

RGB é o sistema de cor para qualquer dispositivo que trabalha com luz. A sigla representa as três cores básicas dessa síntese: vermelho (red), verde (green) e azul (blue). Qualquer tela, monitor, projetor ou dispositivo que emite luz usa RGB como base.

Sempre que o projeto for digital, como posts para redes sociais, sites ou apresentações, o espaço de cor a ser configurado é o RGB.

## O que acontece quando você usa o sistema errado

Enviar um arquivo em RGB para a gráfica é um erro comum e com consequências visíveis. As cores de luz possuem uma gama maior do que as cores de pigmento, o que significa que tons intensos em RGB não têm equivalente direto em tinta.

O resultado prático: um azul vibrante na tela chega impresso como um azul acinzentado e apagado. A diferença não é sutil. A cor perde saturação porque a tinta simplesmente não consegue reproduzir a intensidade que a luz gera.

Programas como Illustrator e Photoshop oferecem presets de sistema de cor para facilitar essa escolha. A orientação é direta: ao criar um arquivo para impressão, acessar as configurações de sistema de cor e selecionar CMYK. Para projetos digitais, selecionar RGB.

## Harmonização de cores: a regra prática para quem está começando

Designers iniciantes tendem a usar muitas cores ao mesmo tempo e a buscar alta saturação nos projetos. Ruan alerta para os dois riscos dessa abordagem: projetos sobrecarregados visualmente e dificuldade de gerenciar a coerência entre as cores.

A orientação direta é trabalhar com no máximo três ou quatro cores por projeto nessa fase. Simplicidade é a melhor estratégia para quem ainda está desenvolvendo o olhar para cor.

O princípio central de harmonização é o contraste. Uma paleta funciona quando combina cores de valores distintos. Se a cor principal é clara, a paleta deve incluir ao menos uma cor escura para gerar contraste. Paletas com apenas cores claras ou apenas cores escuras tendem a parecer apagadas e sem hierarquia visual. Ruan exemplificou: se a cor principal é o amarelo, faz sentido combinar com preto, azul escuro, verde escuro ou vermelho escuro.

## Adobe Color: uma ferramenta para criar e explorar paletas

Ruan apresentou o Adobe Color como uma ferramenta gratuita para auxiliar na criação de paletas. Ela é acessível pelo Google buscando "Adobe Color roda de cores".

Dentro da ferramenta, a seção de harmonia de cores oferece diferentes modelos de combinação: monocromático, tríade, complementar, dividir e complementar, quadrado, composto e sombra. Cada um desses modelos tem uma lógica própria, desenvolvida a partir da teoria de cores da Bauhaus, a primeira escola de design. Esse sistema foi criado por um dos professores da Bauhaus com base em formas geométricas e será explicado em profundidade em aulas futuras da trilha.

Para quem ainda não tem fluência com esses modelos, Ruan indica a seção "Explorar" do Adobe Color. Nela, é possível pesquisar por uma matiz principal, como "orange", e encontrar paletas prontas criadas por outros designers. Essas paletas já foram construídas com atenção ao contraste, o que as torna um ponto de partida seguro para quem está começando.

Ruan reforça que, nessa fase da trilha, as referências visuais são mais úteis do que a teoria. Buscar paletas usadas por outros designers e observar como elas equilibram cores claras e escuras é o caminho mais eficiente para desenvolver o senso cromático antes de aprender a lógica por trás das harmonias.

## Coloque em prática

- Ao criar um novo arquivo, defina o sistema de cor antes de começar: CMYK para impressão, RGB para digital.
- Escolha uma cor principal para o seu projeto e monte uma paleta com no máximo quatro cores, incluindo ao menos um tom escuro para contrastar.
- Acesse o Adobe Color, vá em "Explorar" e pesquise pela sua cor principal. Observe como as paletas encontradas equilibram valores claros e escuros.
