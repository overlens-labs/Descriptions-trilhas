# Formato, Margem e Layout

**Tempo estimado de leitura:** 5 minutos

## Objetivos de aprendizado

Ao final desta aula, você será capaz de:

- Identificar os diferentes formatos de design e suas aplicações em mídias digitais e impressas
- Distinguir as unidades de medida corretas para cada contexto de produção
- Reconhecer o papel da margem e do layout na organização dos elementos dentro de um formato
- Aplicar o conceito de grid como estrutura de apoio para criar composições equilibradas

## O que é formato

Formato é o tamanho e a proporção do material que você está produzindo. É o ponto de partida de qualquer projeto, porque ele determina o espaço dentro do qual todos os outros elementos vão existir. Muitos designers iniciantes ignoram isso, e é justamente aí que os primeiros erros aparecem.

Os formatos se dividem basicamente em dois grupos: retrato, que é verticalizado, e paisagem, que é horizontal. Cada um deles pede uma abordagem diferente para organizar a informação. Um story tem um tipo de espaço. Um post de Instagram é um quadrado. Uma thumbnail de YouTube é um retângulo horizontal. Um site é uma área horizontal com rolagem, o que permite inserir muito mais conteúdo ao longo da página. Cada contexto tem sua lógica própria e exige que você trate a informação de forma específica.

## Unidades de medida por contexto de produção

A escolha da unidade de medida depende do meio em que o projeto vai existir. Para o digital, o padrão é pixel. Para o impresso, a referência muda conforme o tamanho do projeto.

Projetos do tamanho de uma folha são normalmente trabalhados em milímetros. Projetos maiores, como outdoors, usam centímetros ou até metros. Usar a unidade errada pode gerar problemas de escala, de exportação e de entrega ao fornecedor. Se houver dúvida sobre como funcionam as unidades de medida, o ChatGPT pode ajudar a resolver isso rapidamente: basta pedir que explique as unidades básicas como se estivesse falando com uma criança.

## O que é margem e por que ela importa

A margem é o espaço delimitado entre o conteúdo e as bordas do formato. Ela dá respiro ao design. Esse conceito aparece cedo na vida de quem passou pela escola: antes de escrever ou desenhar em uma folha, usava-se uma régua para marcar as margens. Nas aulas de artes também se aprendia a fazer isso. A lógica é a mesma no design: a margem separa, organiza e comunica intenção.

Uma margem bem definida não é apenas estética. Ela orienta o olhar, separa o que precisa ser separado e dá ao design uma aparência de controle. Nos exemplos analisados na aula, é possível ver como a margem cria uma área de respiro ao redor de todos os elementos, alinhando textos, títulos e imagens dentro de um espaço coerente.

## Layout e análise de referências

Layout é o que está dentro do formato: a forma como os elementos foram organizados naquele espaço. Ruan analisou durante a aula um projeto editorial disponível no Behance chamado "Planejamento de Layout", que mostra diversas maneiras diferentes de organizar as mesmas informações dentro de um mesmo formato.

Nos exemplos do projeto, é possível ver arranjos como: duas colunas de texto com imagem abaixo e título em cima; três colunas com imagem posicionada no centro; título destacado no topo com texto distribuído lateralmente; imagem ao lado do texto com colunas paralelas. Cada arranjo cria uma experiência diferente de leitura e conduz o olhar de forma distinta. Ruan recomenda estudar esse projeto com atenção e inclusive reproduzir os desenhos de estrutura manualmente, como se praticava na faculdade.

Jornais são outra fonte valiosa de estudo. Eles concentram um volume grande de informações em um único espaço e precisam resolver o problema de hierarquia e organização com clareza. Títulos com letras maiores conduzem o olhar. Parágrafos com letras menores distribuem o conteúdo. Imagens interagem com o texto. Espaços entre os elementos e margens bem definidas sustentam o conjunto. Observar como isso funciona em um jornal real é uma forma prática de aprender layout.

O Pinterest funciona como uma fonte contínua de referências nesse sentido. À medida que você navega, ele traz mais exemplos, mais ideias, mais variações. O simples ato de observar esses projetos já começa a construir repertório, que é o que o designer precisa para criar bons trabalhos.

## Grid como estrutura de organização

Além de formato e margem, há um terceiro conceito que organiza o design: o grid. O grid mais simples e versátil é o de colunas por linhas. Ele não é difícil de aprender e serve como guia para posicionar os elementos com consistência dentro do espaço. Ruan menciona que disponibiliza na descrição do vídeo o link de uma aula específica sobre esse tipo de grid.

Quando se trabalha com grid, fica muito mais fácil manter harmonia entre os elementos. Todos ficam alinhados a uma estrutura comum, o que cria equilíbrio visual. Um bloco de texto de um lado pode ter como contrapeso uma imagem do outro: isso é uma composição balanceada. Quando o desequilíbrio aparece, ele precisa ser intencional, não acidental.

Cada detalhe conta na composição: o espaço entre letras, o espaço entre linhas, o tamanho da tipografia, a distância entre os elementos, a margem de respiro. Nenhum desses elementos é neutro. Todos eles comunicam algo, e entender isso é parte do que significa fazer design.

## Dominar antes de quebrar

Ruan encerra a aula com uma orientação clara: antes de quebrar as regras de formato, margem e layout, é preciso dominá-las. Isso não é uma limitação, é um processo. Quem ainda está começando precisa primeiro aprender a organizar os elementos dentro de um espaço com intenção e coerência. Só depois faz sentido subverter essa estrutura de forma consciente.

A quebra de regra no design existe e tem seu lugar. Mas ela só funciona quando quem quebra sabe exatamente o que está quebrando e por quê. Quebrar por desconhecimento gera confusão. Quebrar por domínio gera estilo.

## Coloque em prática

- Abra o Pinterest e pesquise "planejamento de layout" ou "layout editorial"
- Escolha três projetos e identifique o formato, a margem e como os elementos estão organizados em cada um
- Observe onde estão os títulos, como os textos se distribuem e onde as imagens estão posicionadas
- Tente reproduzir um dos arranjos que você encontrou usando apenas formas e caixas de texto, sem conteúdo real
- Se tiver dúvidas sobre unidades de medida, pergunte ao ChatGPT pedindo uma explicação simples e direta
