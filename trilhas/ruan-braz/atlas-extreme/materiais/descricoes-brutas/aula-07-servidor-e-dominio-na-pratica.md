# Servidor e domínio na prática

**Tempo estimado de leitura:** 4 minutos

## Objetivos de aprendizado

Ao final desta aula, você será capaz de:

- Distinguir banco vetorial, RAG e grafo de conhecimento
- Reconhecer a diferença entre arquivo local e site público
- Distinguir servidor e domínio

## Contexto e gestão de dados

O resultado de uma IA depende menos da marca do modelo e mais do contexto que ela recebe. Gerenciar dados e entregá-los de forma adequada permite que Claude, Codex, Gemini, Grok ou outro modelo trabalhe com maior precisão.

O Business OS começa como um sistema que organiza as informações do negócio. A partir dessa base, os dados podem ser conectados a agentes e utilizados em decisões, tarefas e processos recorrentes.

## Formas de organizar conhecimento

Um banco vetorial armazena representações que permitem localizar informações por proximidade de significado. O RAG prepara o material, divide o conteúdo em partes e o disponibiliza para recuperação quando uma IA precisa responder com base nesses dados.

O modelo de grafo enfatiza conexões entre informações. Enquanto a busca vetorial trabalha padrões e proximidades, o grafo explicita relações. Ruan associa essa estrutura ao nexialismo porque ambos observam como elementos diferentes se conectam.

A construção começará em um nível mais simples: um sistema para gerir as informações do negócio. As estruturas avançadas são apresentadas como caminhos possíveis para evoluir o uso desses dados.

## Arquivos locais e acesso público

O site criado até aqui está em uma pasta do computador. Quando um arquivo HTML é aberto diretamente, o endereço do navegador exibe o caminho local. Em aplicações executadas com outras tecnologias, o endereço pode aparecer como `localhost`.

Esse endereço funciona apenas para quem possui os arquivos naquele computador. Enviar o caminho a outra pessoa não permite que ela acesse o site. Expor diretamente o computador criaria riscos de segurança, por isso os arquivos precisam ser enviados a uma infraestrutura própria para acesso pela web.

*Para acompanhar a verificação do endereço local do site, assista a partir de 02:56 no vídeo.*

## O que é um servidor

Um servidor é um computador mantido ligado e disponível continuamente para receber solicitações pela internet. Provedores operam grandes estruturas com muitas máquinas e alugam espaços nos quais os arquivos de diferentes projetos ficam armazenados.

Publicar um site significa copiar seus arquivos para esse espaço. Ruan compara o servidor a um lote no qual uma casa é construída. O lote mantém a estrutura disponível, mas ainda é necessário um endereço para que outras pessoas a encontrem.

## O que é um domínio

O domínio é o endereço usado para localizar o site. Assim como uma rua e um número apontam para uma casa, o domínio conduz o navegador até os arquivos hospedados no servidor.

Servidor e domínio cumprem funções diferentes. O servidor mantém os arquivos acessíveis. O domínio fornece o nome público que aponta para esse local. Um projeto pode começar com um endereço fornecido pela plataforma e receber um domínio próprio depois.

## Hospedagem gratuita na Vercel

Empresas de infraestrutura podem oferecer um nível gratuito para criar hábito de uso e cobrar quando o projeto cresce ou utiliza recursos avançados. A Vercel oferece hospedagem gratuita voltada principalmente a projetos pessoais e de estudo.

Para preparar a publicação, acesse a Vercel, selecione `Sign Up` e faça o cadastro, por exemplo com uma conta Google. Neste momento, basta concluir o login. A criação do projeto será realizada pelo agente para reduzir atrito.
