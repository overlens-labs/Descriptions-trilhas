# Criando um site do zero com Claude Code

**Tempo estimado de leitura:** 4 minutos

## Objetivos de aprendizado

Ao final desta aula, você será capaz de:

- Estruturar um pedido inicial de site em linguagem natural
- Executar alterações em links, imagens e páginas com Claude Code
- Aplicar referências visuais e capturas de tela aos prompts
- Distinguir a criação local da publicação de um site

## Começar em uma pasta vazia

Com o Claude Code conectado à pasta `Business OS`, o projeto começa sem arquivos. O poder do agente aparece na capacidade de criar a estrutura necessária diretamente nesse espaço a partir de uma instrução em linguagem natural.

Não é preciso dominar programação para iniciar a demonstração. A primeira tarefa é pedir um site simples de portfólio com headline, texto de apresentação e galeria. Ruan usa como apresentação a atuação como designer nexialista e CEO e fundador da Overlens.

## Dar forma à primeira versão

O pedido também define uma referência visual: design minimalista inspirado no site da Apple, preto e branco e com botões arredondados. O agente traduz essas características para um único arquivo HTML pronto para ser aberto no navegador.

Em menos de dois minutos, o Claude Code cria o arquivo dentro da pasta. A primeira versão é simples, mas já contém chamada, projetos e links. O valor desse começo está na velocidade para produzir uma base concreta que poderá ser refinada por novas instruções.

*Para ver o resultado da primeira versão do site, assista a partir de 03:19 no vídeo.*

## Corrigir links com linguagem natural

Depois da primeira versão, os links podem ser substituídos pelos endereços reais. Basta copiar o URL do Instagram e pedir que o Claude o coloque no site. O mesmo processo pode incluir LinkedIn, e-mail e outras páginas.

O agente modifica o código existente sem exigir que o usuário procure manualmente o trecho responsável por cada link. A pessoa descreve o resultado esperado e fornece os dados corretos para que a IA execute a alteração.

## Adicionar uma imagem ao projeto

Para trocar um elemento visual por uma imagem, primeiro obtenha um arquivo disponível no computador. Na demonstração, Ruan baixa uma fotografia gratuita de um banco de imagens, arrasta o arquivo para a conversa e envia também uma captura do card que deseja alterar.

Quando o agente não encontra a imagem, é necessário informar seu caminho, como a pasta Downloads. O Claude então copia o arquivo para dentro do projeto e atualiza o card. A dificuldade mostra que a linguagem natural não elimina a necessidade de fornecer localização e contexto quando o recurso está fora da pasta de trabalho.

*Para ver o card atualizado com a imagem, assista a partir de 07:39 no vídeo.*

## Local não significa publicado

Abrir o arquivo no navegador permite visualizar o site, mas isso não o torna público. Nesse estágio, todos os arquivos permanecem apenas no computador. A publicação exige uma etapa posterior de deploy, que disponibilizará o projeto na internet.

Essa distinção evita confundir uma prévia local com um endereço acessível por outras pessoas. Primeiro o site é criado e testado localmente. Depois, ele é enviado para uma infraestrutura pública.

## Criar uma página de projeto

Para fazer um card abrir outra página, capture a tela do elemento e peça que o clique leve o usuário a uma página com mais informações sobre o projeto. O Claude Code cria a nova página e conecta os dois arquivos.

Após atualizar o navegador, o clique passa a abrir a explicação do projeto. A alteração exige apenas algumas instruções, mas introduz uma estrutura com mais de uma página e uma navegação entre elas.

*Para ver a navegação entre o card e a página do projeto, assista a partir de 10:58 no vídeo.*

## Refinar por novos pedidos

O processo continua com pedidos incrementais. Um exemplo é solicitar um botão no cabeçalho para alternar o site para dark mode. A IA trabalha sobre a base existente e acrescenta a função conforme a intenção descrita.

O Cowork pode realizar parte dessas tarefas, mas o Claude Code é recomendado porque o projeto avançará e exigirá uma atuação mais completa sobre os arquivos. A criação de um site simples já é acessível e tende a se tornar comum, enquanto o diferencial está em avançar para sistemas mais completos, como o Business OS.

## Coloque em prática

Peça ao Claude Code um portfólio com headline, apresentação e galeria. Defina cores e uma referência visual. Depois, substitua um link, adicione uma imagem local e solicite uma página detalhada para um dos cards.
