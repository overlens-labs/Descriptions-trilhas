# Próximos passos

**Tempo estimado de leitura:** 1 minuto

## Objetivos de aprendizado

Ao final desta aula, você será capaz de:

- Reconhecer o que foi construído na primeira parte prática
- Identificar as próximas camadas do Brand System
- Reconhecer a conexão entre banco de dados, autenticação, storage e IA

## Base do sistema construída

A aula encerra a primeira parte prática afirmando que a base do sistema foi construída. O design ainda será refinado depois, mas o aluno já viu o processo principal: basta pedir à inteligência artificial, orientar o que precisa ser feito e ela vai construindo o sistema junto com o usuário.

Essa base inclui a estrutura inicial do Brand System, a interface e a lógica para começar a transformar documentos de marca em uma experiência navegável. O foco, até esse momento, foi fazer o projeto existir localmente e mostrar como a IA consegue acelerar a criação.

O Ruan reforça que a aparência ainda não está finalizada. Ele pretende tratar o design antes da próxima aula, mostrando que a criação com IA é iterativa: primeiro se constrói a estrutura, depois se refina visual, fluxo e detalhes.

## Próximas camadas do Brand System

O próximo passo é conectar banco de dados, autenticação e storage ao Brand System. Essas três camadas transformam o sistema local em uma plataforma mais próxima do uso real.

O banco de dados guardará informações e documentos. A autenticação permitirá login, criação de contas e controle de acesso. O storage armazenará arquivos, como imagens, logotipos, PDFs e outros ativos da marca.

Com essas camadas conectadas, o sistema poderá ser publicado e integrado com inteligências artificiais. A aula posiciona esse momento como a passagem da interface local para um Brand System mais completo, capaz de funcionar para outras pessoas.

## Coloque em prática

Revise se a base do seu projeto local está funcionando antes de avançar.

Depois, anote quais partes precisarão de banco de dados, quais precisarão de storage e quais precisarão de autenticação.
